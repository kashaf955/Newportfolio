A few things that shipped

Full-stack builds, each one taken from a blank repo to a working product on the MERN stack.

UET Panda

A full-stack food ordering system covering the full customer flow: browsing a menu, managing a cart, and placing an order, built on the MERN stack.

  • React frontend for browsing, cart management, and checkout.
  • Express + Node.js API handling orders and menu data.
  • MongoDB for persisting menu items, carts, and orders.

HomeVista

A full-stack MERN real estate platform with user authentication and property management, letting users list, browse, and manage property listings.

  • Authentication flow for property owners and browsers.
  • Property listing management backed by a MongoDB data model.
  • React interface for browsing and managing listings.

Live Demo GitHub

CozyCorner

A full-stack booking and listing web application built on the MERN stack, handling listing discovery and reservation flow.

  • React interface for browsing and booking listings.
  • Express + Node.js API for managing listings and bookings.
  • MongoDB backing the listing and booking data.
