UET Panda

A full-stack food ordering system covering the full customer flow: browsing a menu, managing a cart, and placing an order, built on the MERN stack.

  • React frontend for browsing, cart management, and checkout.
  • Express + Node.js API handling orders and menu data.
  • MongoDB for persisting menu items, carts, and orders.
